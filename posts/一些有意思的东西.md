2.rst

`.rst` 一般指 **reStructuredText** 文件，是一种轻量级标记语言，作用和 Markdown（`.md`）有点像，但语法更严格、功能也更适合大型技术文档。

vscode里安装reStructuredText 扩展，mac里安装Sphinx：

```shell
brew install sphinx-doc
```

再安装sphinx-autobuild：

```shell
pipx install sphinx-autobuild #需要先brew install pipx
```

![image-20260910212037032](https://gitee.com/wenswuu/pictures/raw/master/image-20260910212037032.webp)

适合用来编写一些比较大型的技术文档，例如[RMC的说明文档](https://rmc-doc-rich.reallab.org.cn/zh-cn/latest/index.html)。
